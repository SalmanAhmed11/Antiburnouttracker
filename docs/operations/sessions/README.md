# Session Records

Use one concise, sanitised file per meaningful session, named `YYYY-MM-DD-topic.md`, based on `TEMPLATE.md`.

**Why not store every raw agent response?** Raw transcripts are noisy, may contain credentials or sensitive information, and are not reliable as approved requirements. Record decision IDs, commands/tests, changed files, PR/commit links and explicit next actions. When verbatim prompts materially affect a design or code decision, keep the reviewed version in `prompts/` and link it here.

This folder is a project handoff, not a private chat archive.
